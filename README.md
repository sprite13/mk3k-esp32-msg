# M5StickC Plus2 Telegram ANCS

Прошивка для M5StickC Plus2 на чистом ESP-IDF получает уведомления Telegram с
iPhone через Apple Notification Center Service (ANCS), показывает их на ST7789
и хранит пять последних уведомлений в RAM. Arduino, M5Unified и Wi-Fi не
используются.

## Требования и установка ESP-IDF

- M5StickC Plus2 и USB-кабель с передачей данных;
- iPhone с Telegram;
- Linux с Git, Python и стандартными зависимостями ESP-IDF;
- закрепленная версия ESP-IDF `v6.1.1`.

Из домашнего каталога:

```bash
mkdir -p "$HOME/esp"
git clone --depth 1 --branch v6.1.1 --recursive \
  https://github.com/espressif/esp-idf.git \
  "$HOME/esp/esp-idf-v6.1.1"
"$HOME/esp/esp-idf-v6.1.1/install.sh" esp32
source "$HOME/esp/esp-idf-v6.1.1/export.sh"
idf.py --version
```

Последняя команда должна сообщить `ESP-IDF v6.1.1`. Если каталог уже есть, не
клонируйте его повторно; проверьте тег командой:

```bash
git -C "$HOME/esp/esp-idf-v6.1.1" describe --tags --exact-match
```

## Сборка, прошивка и monitor

Из корня рабочего дерева:

```bash
source "$HOME/esp/esp-idf-v6.1.1/export.sh"
cd repos/m5stickc-telegram-ancs
idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

При необходимости замените `/dev/ttyUSB0` на порт платы. Готовый образ:
`build/m5stickc_telegram_ancs.bin`. Для выхода из serial monitor нажмите
`Ctrl+]`.

## Сопряжение с iPhone

1. После запуска откройте на iPhone `Настройки -> Bluetooth`.
2. Выберите устройство `M5 ANCS` и подтвердите запрос сопряжения.
3. Разрешите устройству доступ к системным уведомлениям, если iOS покажет такой
   запрос. В свойствах `M5 ANCS` оставьте передачу системных уведомлений
   включенной.
4. Дождитесь состояния подключения на экране M5StickC Plus2.

Устройство использует режим BLE без клавиатуры и дисплея для ввода кода. Не
отправляйте в чат пароли, секреты, коды сопряжения или снимки экрана с ними. Если
iOS неожиданно показывает код, проверьте имя устройства и выполняйте
подтверждение только локально на своих устройствах.

Чтобы удалить сохраненную пару, удерживайте кнопку B не менее 5 секунд. На
экране отображается прогресс; после завершения удалите старую запись `M5 ANCS`
в настройках Bluetooth iPhone и выполните сопряжение заново.

## Telegram и previews в iOS

ANCS передает текст только в пределах настроек приватности iOS. Включите
уведомления и previews:

1. `Настройки iOS -> Уведомления -> Telegram -> Допуск уведомлений`.
2. В том же разделе откройте `Показ миниатюр` (`Show Previews`) и выберите
   `Всегда` либо `Если разблокировано`, учитывая выбранную модель приватности.
3. В Telegram откройте `Настройки -> Уведомления и звуки` и включите нужные
   личные сообщения и группы.

При выключенных previews на экране может быть только имя приложения или
обобщенный текст без отправителя и сообщения. Прошивка не обходит ограничения
приватности iOS.

## Управление и очередь

- Кнопка A: перейти к более старому уведомлению.
- Короткое нажатие B: перейти к более новому уведомлению.
- Удержание B 5 секунд: удалить BLE bond и начать новое сопряжение.
- Новое принятое уведомление включает экран, выбирается текущим и подает
  короткий звуковой сигнал.
- Через 10 секунд без действия подсветка и панель переходят в сон; кнопка или
  новое событие будят экран.

В пользовательской очереди находятся пять последних уведомлений Telegram.
Шестое вытесняет самое старое. Внутренняя очередь приема рассчитана на восемь
ожидающих событий; при всплеске сохраняются новые события, вытеснения
записываются в monitor. Уведомления других приложений отбрасываются. Очередь
находится только в RAM и очищается после перезапуска.

## Энергопотребление

Основной профиль вызывает `esp_pm_configure()` при запуске и включает DFS в
диапазоне 80..240 МГц. Ошибка конфигурации записывается в monitor, после чего
приложение продолжает работу без обещания настроенного DFS. Automatic light
sleep в `sdkconfig.defaults` выключен, поэтому базовый профиль не меняет режим
ожидания BLE.

Отдельный `sdkconfig.light_sleep` предназначен только для последующего
аппаратного A/B-теста. Собирайте его в отдельный каталог, чтобы не смешивать с
базовым образом:

```bash
source "$HOME/esp/esp-idf-v6.1.1/export.sh"
cd repos/m5stickc-telegram-ancs
idf.py -B build-light-sleep \
  -DSDKCONFIG="$PWD/build-light-sleep/sdkconfig" \
  -DSDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.light_sleep" \
  set-target esp32
idf.py -B build-light-sleep \
  -DSDKCONFIG="$PWD/build-light-sleep/sdkconfig" \
  -DSDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.light_sleep" \
  build
idf.py -B build-light-sleep \
  -DSDKCONFIG="$PWD/build-light-sleep/sdkconfig" \
  -p /dev/ttyUSB0 flash monitor
```

Этот профиль включает automatic light sleep и не считается проверенным для
эксплуатации. Перед его использованием нужно на реальной плате сравнить ток,
стабильность сопряжения, прием уведомлений, выход из зоны BLE, возврат и задержку
переподключения с базовым профилем. Интервалы BLE, advertising, подписок ANCS и
таймаутов приложения код профиля не меняет.

## Автоматические проверки

Host-тесты с ASan/UBSan:

```bash
rm -rf /tmp/m5-ancs-host
cmake -S tests/host -B /tmp/m5-ancs-host \
  -DCMAKE_C_FLAGS="-Wall -Wextra -Werror -fsanitize=address,undefined -fno-omit-frame-pointer"
cmake --build /tmp/m5-ancs-host
ctest --test-dir /tmp/m5-ancs-host --output-on-failure
```

Чистая сборка и размер основного образа:

```bash
idf.py fullclean
idf.py build
idf.py size
```

## Аппаратная проверка

Статус физических проверок и поля для результатов находятся в
[`docs/hardware-validation.md`](docs/hardware-validation.md). Автоматическая
сборка не подтверждает экран, кнопки, буззер, ADC, BLE с iPhone, ток ожидания или
время работы. Заполняйте матрицу только после проверки на реальном M5StickC
Plus2; отсутствие результата нельзя отмечать как успешную проверку.

## Известные ограничения

- Нужен iPhone: ANCS не является протоколом уведомлений Android.
- Принимается только iOS bundle ID Telegram `ph.telegra.Telegraph`.
- Доступный текст зависит от previews, блокировки iPhone и политики iOS.
- Emoji и неподдерживаемые символы удаляются; длинные поля обрезаются до
  фиксированных буферов и размеров экрана.
- Хранятся только пять уведомлений в RAM, без истории после перезапуска.
- Действия над уведомлением, ответы и синхронизация прочитанного не реализованы.
- Процент батареи является оценкой по фиксированной LiPo-таблице; без доступной
  ADC-калибровки показывается неизвестное значение.
- Работа на физической плате и experimental light-sleep профиль пока не
  подтверждены; актуальные незакрытые пункты перечислены в аппаратной матрице.
