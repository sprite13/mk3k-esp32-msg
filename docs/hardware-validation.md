# Матрица аппаратной проверки

Эта матрица содержит только физические проверки. На момент создания ни один
пункт ниже не выполнялся на реальном M5StickC Plus2. Статус `НЕ ПРОВЕРЕНО` не
означает успех; поля результата оставлены для будущего A/B-прогона.

Используемые статусы: `НЕ ПРОВЕРЕНО`, `PASS`, `FAIL`, `BLOCKED`. Ставить `PASS`
можно только после наблюдения на указанном оборудовании и записи результата.
